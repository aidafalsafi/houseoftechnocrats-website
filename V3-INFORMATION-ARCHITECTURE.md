# House of Technocrats V3

V3 is an independent copy of V1 with the information architecture from `New Tree 2.jpg` applied as a linked bilingual site.

## Primary Navigation

- Home: `index.html`
- Continuity: `continuity.html`
- Deep Blue Radar
  - Overview and method: `radar.html`
  - Interactive Explorer: `radar-view.html`
  - Selected Category: `category-continuity-architecture.html`
  - Pattern record: `pattern-modular-survivability.html`
  - Reports and updates: `radar.html#reports`
- Insights
  - Story Amir / Podcast: `podcast-ecosystem.html`
  - Interaction Amin / Videocast: `video-core-banking.html`
  - Toolkit Hossein / Gamecast: `toolkit-gamecast.html`
- Technocratic Thinking: `technocratic-thinking.html`
  - Contains the About the Technocratic Book section
  - Contains the About the Technocratic Method section
- House
  - About House: `house.html`
  - Participate: `participate.html`
    - Invitation: `invitation.html`
    - Membership: `membership.html`
    - Referral: `referral.html`
    - Join a conversation: `join-conversation.html`
- People
  - Directory: `people.html`
  - Person profile: `person.html`
- Technocratic Service Store: `services.html`
  - Contains the Current Services section
  - Contains the Future Services section
- About Us: `about-us.html`

Legacy utility and detail files remain available for existing direct URLs and search results, but they are not exposed as separate top-level navigation products in V3. The active header uses dropdowns only for Deep Blue Radar, Insights and House.
